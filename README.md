# Blog Tưởng Văn Thăng

Mã nguồn blog cá nhân tại [blog.tuongvanthang.com](https://blog.tuongvanthang.com): ghi chép về nghề thủy sản, thực phẩm, kinh doanh một mình và ứng dụng công nghệ.

- `index.html`: danh sách bài viết
- `bai-viet/`: mỗi bài một file HTML
- `style.css`: giao diện chung

HTML và CSS tĩnh, deploy qua Cloudflare Pages.
